# 回响 · 网页版

**打开浏览器，直接用 TeamSpeak。** 不用安装任何客户端，填上服务器地址就能进频道，像桌面客户端一样聊天、语音、传文件、共享屏幕和摄像头。也提供 Windows 免安装启动器，双击即可进入。

> **安卓版（Android 客户端）**：<https://github.com/youareanimal/huixiang>
>
> 本项目与安卓版是同一个「回响」的不同端。本项目的隐私协议、用户协议及其他相关协议与政策，均与安卓版仓库保持一致，具体内容请以该仓库中的对应文件为准。

> **注意**：本项目仍处于开发阶段，部分功能尚不完全，欢迎反馈与指正。

## 功能

**连接与账号**

- 匿名游客即可进入，也支持登录 myTeamSpeak 账号；登录后连接会带上账号身份，服务器可显示账号徽章。
- 支持填写服务器密码与直接进入指定频道（含频道密码）；信息栏实时显示网络延迟。
- 「记住登录」：登录一次后 30 天内免重输密码（可在服务端调整或关闭）。
- 云书签：登录后读取账号的服务器书签，点一条即自动填入地址、昵称和服务器密码。

**频道与成员**

- 频道树：名称、密码标记、话题、人数上限、编解码器、权限等级、分隔符频道。
- 切换频道（含频道密码）、重命名自己。
- 成员列表：昵称、UID、说话状态、离开、输入/输出静音、talk power、优先发言人、频道组与服务器组。
- 成员进出本频道时，右下角文字提示并播放提示音。
- 用户资料卡：悬停头像查看 UID、频道、身份组、客户端、地区、状态。
- 暂离（Away）：可切换暂离并填写离开留言，实时同步到服务器与所有客户端。

**语音**

- 双向 Opus 语音，麦克风与扬声器静音状态实时同步到服务器。
- 三档说话方式：自动（检测到说话才发送）、常开、按住说话。
- 提示：语音功能需要浏览器支持 WebCodecs。

**文字**

- 频道消息与私聊收发。
- 频道聊天历史：本地保留最近记录，滚动到顶部可继续向前翻页。

**屏幕 / 摄像头共享**

- 通过 WebRTC 与对方直连，既能观看别人的画面，也能自己开播；支持全屏与静音。
- 共享为点对点（mesh），观看的人越多，发布者上行带宽占用越高。

**频道文件**

- 浏览、下载、上传、新建文件夹、改名、删除频道文件区里的文件。
- 文件保存在 TeamSpeak 服务器上，安卓 App、官方客户端与网页版看到的是同一批。
- 上传、删除、改名等写操作均带二次确认，并按服务器权限裁决。

**频道管理**

- 建 / 删 / 改频道（名称、描述、类型、编解码与音质、人数上限、密码）。
- 踢人与封禁（可设时长与原因）；权限由 TeamSpeak 服务器判定，失败会给出中文原因。

**账号与好友**

- 自己的 myTeamSpeak 头像可上传 / 更换 / 删除。
- 好友列表显示昵称 / 备注；对方在本服务器在线时走服务器私聊（官方客户端可见），不在时走云端聊天（Matrix）。

**其他**

- 可作为 PWA 安装到桌面或手机主屏。
- 随时主动离开服务器，之后可再次连接。

## 使用

### 在浏览器中打开

访问部署好的回响网页地址（例如 <https://ts.xinmouren.cn/>），按页面提示填写服务器地址、昵称即可进入；如需账号功能，在连接页登录 myTeamSpeak。

### Windows 桌面启动器（免安装）

仓库根目录附带两个**等价**的启动器，方便不想开浏览器、或没有开发环境的人直接双击进入网页版：

- **`回响.exe`** —— 带回响图标，双击即用（推荐）。
- **`回响.bat`** —— 无图标备选；若 exe 被安全软件误拦，可改用此文件，或直接用记事本打开审查逻辑。

两者行为一致：自动查找本机 Microsoft Edge，用一个**独立配置目录**（`%LocalAppData%\HuixiangLowMem`，不干扰日常 Edge）以 `--app=https://ts.xinmouren.cn/` 启动回响网页版，并加 `--disable-extensions` 禁用所有扩展以尽量省内存。**首次使用需在弹出的页面里登录一次**，之后自动记住。

- 改服务器地址：`回响.exe` 内置固定为 `https://ts.xinmouren.cn/`；`回响.bat` 可用记事本改顶部的 `APP_URL`。
- `回响.exe` 若探测到首选目录不可写，会自动回退到 `%TEMP%`，再退到程序所在目录，避免「访问被拒绝」。
- 自编译 exe 首次运行可能触发 SmartScreen「未知发布者」，点「更多信息 → 仍要运行」即可。

### 自己部署

想自建一套回响，可按 [deploy/DEPLOY.md](deploy/DEPLOY.md) 从空服务器一路部署到验收；最简单的 Docker 方式：

```bash
docker build -t huixiang-web .
docker run -d --restart=always -p 8080:8080 --name huixiang-web huixiang-web
```

前端在 `client`（React + Semi Design），构建产物（`client/dist`）由网关一并托管；开发与构建细节见 [client/README.md](client/README.md)。

## 项目结构

本仓库由前端（**client**）、网关（**gateway**）、协议栈（**tsproto**）三部分组成，另含部署与启动器相关文件：

```text
huixiang-web/
├─ client/                 前端：React + TypeScript + Vite + Semi Design
│  ├─ index.html
│  ├─ vite.config.ts
│  ├─ public/              静态资源、PWA 图标与 manifest
│  └─ src/
│     ├─ App.tsx           应用根组件与整体状态
│     ├─ gateway.ts        与网关的 WebSocket 通信、请求/推送分发
│     ├─ protocol.ts       前后端共享的消息类型与协议常量
│     ├─ account.ts        账号、登录与云书签
│     ├─ files.ts          频道文件操作
│     ├─ chatHistory.ts    聊天历史本地缓存
│     ├─ presence.ts       在线状态
│     ├─ stream.ts         屏幕 / 摄像头串流（WebRTC）
│     ├─ audio/            语音采集与播放（mic.ts、player.ts、capture-worklet.js 等）
│     └─ components/       界面组件（ServerPage、ChannelTree、ChatPanel、FilesPanel 等）
│
├─ gateway/                网关：Kotlin + Ktor + Netty（纯 JVM 服务）
│  ├─ src/main/kotlin/web/                 网关源码
│  ├─ src/main/resources/                  资源
│  └─ src/test/kotlin/...                  单元测试
│
├─ tsproto/                协议栈：纯 Kotlin 实现的 TeamSpeak 协议（无 Android 依赖）
│  └─ src/main/kotlin/tsproto/
│     ├─ TsClient.kt       UDP 连接、握手、分包与加密收发
│     ├─ Crypto.kt         AES-128-EAX 等加解密
│     ├─ Identity.kt       身份密钥
│     ├─ FileTransfer.kt   频道文件传输
│     ├─ ServerModel.kt    服务器 / 频道 / 成员模型
│     ├─ MyTs*.kt          myTeamSpeak 账号、书签、头像、语音数据
│     ├─ MatrixCloud.kt    云端聊天（Matrix）
│     └─ ...               命令解析、QuickLZ、License 等
│
├─ deploy/                 部署：DEPLOY.md 部署手册、verify.sh 验收脚本
├─ Dockerfile              Docker 多阶段构建（前端 → 网关 → 运行镜像）
├─ gradlew / gradlew.bat   Gradle 包装器（构建网关与协议栈）
├─ 回响.exe / 回响.bat     Windows 免安装启动器
└─ CHANGELOG.md / LICENSE / PRIVACY.md / README.md
```

- **`client/`**：浏览器前端，构建产物 `client/dist` 由网关直接托管。
- **`gateway/`**：WebSocket / HTTP 网关，负责浏览器连接、会话管理、文件与静态资源路由；构建时通过 `kotlin.srcDir` 直接引用 `tsproto` 源码，因此两者需一起构建。
- **`tsproto/`**：TeamSpeak 协议栈，独立、无 Android 依赖，可单独复用。其协议实现移植自开源项目 [PocketTS](https://github.com/korppujauho/pocketts)（详见文末「[致谢](#致谢)」）。

## 浏览器要求

| 能力 | 需要 |
|---|---|
| 语音 | WebCodecs（`AudioDecoder` / `AudioEncoder`）：Chrome/Edge 94+、Safari 16.4+、Firefox 130+ |
| 文字、频道等 | 任何现代浏览器 |

不支持 WebCodecs 时页面顶部会提示，文字和频道功能照常可用。

## 隐私协议

回响网页版与安卓版遵循一致的隐私原则：无应用自有账号、无广告、无分析或崩溃上报。

- **账号密码不留在浏览器。** 密码只在登录时经加密连接交给服务端换取会话，浏览器不保存密码、令牌或书签密钥；「记住登录」在浏览器里只保存一枚脚本读不到的随机 cookie。
- **建议对外部署启用 HTTPS。** 公开部署时请配置 TLS，并尽量设置访问口令，避免服务被他人当作代理使用。
- **文件与头像**访问使用仅对当前标签页有效的临时令牌，断开即失效。
- 完整说明见 [PRIVACY.md](PRIVACY.md)；安卓版的完整隐私说明见 <https://github.com/youareanimal/huixiang/blob/main/PRIVACY.md>，两者保持一致。
